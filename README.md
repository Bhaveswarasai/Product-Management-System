# Product Management System - using springboot

A **Product Management System** built using **Java and Spring Boot** that performs **CRUD (Create, Read, Update, Delete)** operations on products.  
The project demonstrates the implementation of RESTful APIs using Spring Boot, connected to a database (e.g., MySQL) with Spring Data JPA for data persistence and interaction.

---

## 🧩 Overview

This application allows users to:
- Add new products
- Retrieve all products
- Retrieve product details by ID
- Update product information
- Delete a product

It follows a layered architecture with:
- Controllers for API endpoints
- Services for business logic
- Repositories for database interaction

This project is a great starter template for inventory and management systems. It can easily be extended with categories, suppliers, authentication, pagination, etc.

---

## 🚀 Features

✔ Create a new product  
✔ Get all products  
✔ Get product by ID  
✔ Update an existing product  
✔ Delete a product by ID  
✔ Clean REST API structure  
✔ Java + Spring Boot + JPA based implementation
